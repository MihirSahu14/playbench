# dodge-godot (experimental, unverified)

A Godot 4.3+ port of `examples/dodge-web` for the playbench harness's Godot transport: the same 20-second dodge game, with the enemy table as constants in `main.gd` instead of a CSV, seeded through `probe_seed`, readable through `probe_state` / `probe_actions` / `probe_bot` on the root node, and the planted bugs selected with user args (`godot --path examples/dodge-godot -- bug=softlock` or `-- bug=crash`). Run it with `godot --path examples/dodge-godot` (Enter or Space starts, arrow keys move); the `Web` preset in `export_presets.cfg` exports a non-threaded build to `build/web/index.html`. It was written without a Godot binary on hand, so treat it as experimental until `godot --headless --path examples/dodge-godot --quit-after 120` has been run with a real Godot 4.3+ binary and shows no `SCRIPT ERROR`.
